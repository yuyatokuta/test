# Website XXX

A minimal personal website for a mathematician — built using plain HTML5 and CSS.

## 📂 Structure

```
.
├── index.html          # Main page
├── research.html       # Research interests and projects
├── teaching.html       # Teaching activities and courses
├── publications.html   # Selected papers and preprints
├── contact.html        # Contact information
├── style.css           # Shared CSS for layout and typography
└── LICENSE             # BSD 3-Clause License
```

## ✨ Features

- Pure **HTML5 + CSS3**, no frameworks required  
- Fully responsive layout (mobile-friendly)  
- Semantic HTML (`<header>`, `<main>`, `<article>`, `<aside>`, `<footer>`)  
- Math-ready (via [MathJax](https://www.mathjax.org/), optional)  
- Ideal for hosting on GitHub Pages

## 🚀 Usage

To preview locally:

```bash
git clone https://github.com/yourusername/test.git
cd test
open index.html   # or use your browser to open this file
```

To publish via GitHub Pages:

1. Go to **Settings → Pages**
2. Under “Source,” select **Branch: main** and **/ (root)**
3. Save — your site will appear at  
   `https://yourusername.github.io/test/`

## 🧩 Customization

Edit the following fields in each HTML file:
- `<title>` and `<h1>` for your site name
- `<meta name="description">` for SEO
- Add your real email address and links in `contact.html`
- Adjust color, font, and spacing in `style.css`
